# CMwId / MwId

Date: 2026-08-18. Binary: Trackmania.exe in Ghidra project `tm2020-headless` on x-left.
Live: Proton `Trackmania.exe` (editor map `redisland-mb-test`) was up; this note is from decompile, not a live intern-table dump.

## Verdict — is this MwId defined?

The engine’s null / “not defined” value is **`0xFFFFFFFF`**.

```angelscript
// recommended
bool defined = id.Value != uint(-1);

// also works for the common case (ToString32 mode 0)
bool defined = id.GetName() != "Unassigned";
```

That is what the game writes for empty / `"Unassigned"` / `"NullId"`, what `MwId()` constructs, and what callers test (`if (id != -1)` at `CMwId_ResolveCString` consumers such as `0x1406f9f40`).

**Do not** treat `Value == 0` as undefined. A freshly constructed `CMwNod` has `Id = 0` at `+0x08`, which is a **numeric** id whose name is `"#0"`.

**Do not** treat `GetName() == ""` as undefined. Empty text is also the fallback for a tag-01 id whose intern lookup returns null, and for tag-11 when `MwId_ToString32` is called with `mode != 0`.

Openplanet already uses the name test in-tree:

- `ItemEditor::HasItemBeenSaved` — `ItemModel.IdName != "Unassigned"`
- tm-archivist — `map.Id.GetName() == "Unassigned"`

`MwId.SetName("")`, `SetName("Unassigned")`, and `SetName("NullId")` all store `0xFFFFFFFF`.

## Bit layout

`CMwId` is a **u32**. Top two bits are a tag; the low 30 bits are the payload.

| tag `(value & 0xC0000000)` | meaning | `MwId_ToString32` / `GetName()` (mode 0) |
|---|---|---|
| `00` `0x00000000` | numeric / `#N` | `"#<low30>"` |
| `01` `0x40000000` | interned name | interned C string, or `""` if resolve fails |
| `10` `0x80000000` | error | `"Internal Error"` |
| `11` `0xC0000000` | unassigned class | `"Unassigned"` (or `""` if mode ≠ 0) |

Canonical null is all bits set: **`0xFFFFFFFF = tag 11 | 0x3FFFFFFF`**.

A named id is `0x40000000 | ((tableIndex << 16) | slot)`. Some E++ dumps store only the 30-bit index and OR the tag back on (`WFC.as` `_DumpCI_IDs`: `next | 0x40000000`).

### Finer tests

| question | test |
|---|---|
| assigned at all (numeric **or** named) | `value != 0xFFFFFFFF` |
| interned name (not `#N`) | `(value & 0xC0000000) == 0x40000000` |
| currently resolvable C string | `CMwId_ResolveCString(&id) != NULL` (native only) |
| this *string* already interned, do not create | `CMwId_FromString32(&out, &str, lookupOnly=1)` returns false on miss (native only; Openplanet `SetName` always creates) |

`CMwId_ResolveCString` returns null for every non-`01` tag, including `0xFFFFFFFF`. It does **not** range-check the table index or reject an empty slot (`0xFFFFFFFF` offset). A fabricated tag-01 value can therefore return a garbage pointer. For plugin code, stick to `Value != uint(-1)`.

## How names become ids

`MwIdString_IsNullSpelling` (`0x1402d4aa0`) is true for:

- length 0
- length 10 and bytes equal `"Unassigned"` (`0x141b72ae0`)
- length 6 and bytes equal `"NullId"` (`0x141b72aec`)

Then:

- `MwId_FromString32OrNull` (`0x1402d4d60`) — null spelling → write `0xFFFFFFFF`; else intern and OR `0x40000000`. No `#` numeric path.
- `CMwId_FromString32` (`0x1402d4b40`) — same null spelling; **or** a leading `'#'` parses as a tag-00 numeric (`value & 0x3fffffff`); else intern. `lookupOnly != 0` + miss → return false, dest unchanged.

Openplanet `MwId.SetName` / `nod.IdName = ...` is the create path (intern if missing). There is no script binding for lookup-only.

## Resolve / stringify

`CMwId_ResolveCString` (`0x1402d47e0`) — **RCX is `CMwId*`**, not a copied u32 (already noted on the plate, 2026-07-22):

```
if ((id & 0xC0000000) != 0x40000000) return NULL;
table = g_CMwId_HashTables[id.tableIndex];   // tableIndex = (id & 0x3fffffff) >> 16
offset = table.pSlots[id & 0xFFFF];          // empty slot in the table is 0xFFFFFFFF
return g_CMwId_StringBlob.p + offset;
```

`MwId_ToString32` (`0x1402d48f0`) is what script `GetName()` / `IdName` getter goes through (CMwNod script prop `0x1001000` in `FUN_1402cfb80`). Mode 0 is the human spelling (`"Unassigned"`, `"#N"`, interned name).

## Intern tables

`CMwId_StaticInit` (`0x1402d4480`, string `"CMwId::StaticInit"`):

- string blob grown to **1_000_000** bytes if smaller
- hash table 0 allocated with `next_prime(20000)` buckets, filled with `0xFFFFFFFF`
- table count = 1
- heap singleton `u32 = 0xFFFFFFFF` stored at `g_CMwId_NullIdSingleton` — script `CMwNod.Id` getter (`0x1001001`) returns this pointer when the nod’s id accessor is null

`CMwId_InternString32` (`0x1402d4630`):

- hash = MurmurHash2(`Hash_Murmur2` @ `0x1401262f0`) of the bytes, seed **`0x57489862`**
- bucket = `hash % nBuckets`, step = `hash % (nBuckets-2) + 1`
- probe 5 slots; on miss go to the next table (allocate on demand)
- insert: append `bytes + NUL` to the blob, store the blob offset in the slot
- return `(tableIndex << 16) | slot` (no tag; callers OR `0x40000000`)
- `lookupOnly != 0` and first empty slot → return `-1`

Compare is the engine string-view equality helper at `0x14010cc90` (length then bytes).

## Openplanet / E++

Script `MwId` is a 4-byte value type:

- `MwId()` → `0xFFFFFFFF`
- `MwId(uint)` / `.Value` get/set
- `.GetName()` → `MwId_ToString32` mode 0
- `.SetName(string)` → intern / null-spelling

E++ helpers: `GetMwId` / `GetMwIdName` (`src/Dev.as`, via a throwaway `CGameItemModel.IdName`), and `StrToMwIdValue` / `MwIdValueToStr` (`src/UI/TabMeta.as`, via a global `MwId`).

`CMwNod.Id` is the field at `+0x08`. `CMwNod.IdName` is the string view of that same field.
