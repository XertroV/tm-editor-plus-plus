# CMwId / MwId

Date: 2026-08-18. Binary: Trackmania.exe in Ghidra project `tm2020-headless` on x-left.
Live: Proton `Trackmania.exe` (editor map `redisland-mb-test`) was up; this note is from decompile, not a live intern-table dump.

## Verdict — is this MwId defined?

Two different questions.

**1. Is this the Unassigned sentinel?** Engine null is **`0xFFFFFFFF`**. `MwId()` constructs it. Empty / `"Unassigned"` / `"NullId"` all store it. Game code tests `id != -1`.

```angelscript
bool assigned = id.Value != uint(-1);
```

That is enough for ids you got from the engine (`nod.Id`, `SetName`, inventory, …).

**2. Is this random u32 a live interned name?** Example: `0x400249b5`. Tag `01`, so `Value != -1` is true, but that does **not** mean a string exists.

Live 2026-08-18 on this process: table count = 3, table 2 slot `0x49b5` = **`0xFFFFFFFF` (empty)**. Not defined.

`GetName()` / `IdName` is **not** a safe test for question 2. `CMwId_ResolveCString` does not check table count or empty slots. For this id it would return `blob + 0xFFFFFFFF` and strlen that. Openplanet has no `MwId.IsDefined`.

Safe plugin check: walk the intern tables (see below). `Dev::SafeRead` the slot; empty / OOB table / null `pSlots` / `slot >= buckets` → not defined.

**Do not** treat `Value == 0` as undefined. A freshly constructed `CMwNod` has `Id = 0` at `+0x08`, which is a **numeric** id whose name is `"#0"`.

**Do not** treat `GetName() == ""` as undefined. Empty text is also the fallback for a tag-01 id whose intern lookup returns null, and for tag-11 when `MwId_ToString32` is called with `mode != 0`.

Openplanet already uses the name test in-tree:

- `ItemEditor::HasItemBeenSaved` — `ItemModel.IdName != "Unassigned"`
- tm-archivist — `map.Id.GetName() == "Unassigned"`

`MwId.SetName("")`, `SetName("Unassigned")`, and `SetName("NullId")` all store `0xFFFFFFFF`.

## Bit layout

`CMwId` is a **u32**. Top two bits are a tag; the low 30 bits are the payload.

| tag `(value & 0xC0000000)` | meaning | `MwId_ToString32` / `GetName()` (mode 0) |
|---|---|---|
| `00` `0x00000000` | numeric / `#N` | `"#<low30>"` |
| `01` `0x40000000` | interned name | interned C string, or `""` if resolve fails |
| `10` `0x80000000` | error | `"Internal Error"` |
| `11` `0xC0000000` | unassigned class | `"Unassigned"` (or `""` if mode ≠ 0) |

Canonical null is all bits set: **`0xFFFFFFFF = tag 11 | 0x3FFFFFFF`**.

A named id is `0x40000000 | ((tableIndex << 16) | slot)`. Some E++ dumps store only the 30-bit index and OR the tag back on (`WFC.as` `_DumpCI_IDs`: `next | 0x40000000`).

### Finer tests

| question | test |
|---|---|
| assigned at all (numeric **or** named) | `value != 0xFFFFFFFF` |
| interned name (not `#N`) | `(value & 0xC0000000) == 0x40000000` |
| currently resolvable C string | `CMwId_ResolveCString(&id) != NULL` (native only) |
| this *string* already interned, do not create | `CMwId_FromString32(&out, &str, lookupOnly=1)` returns false on miss (native only; Openplanet `SetName` always creates) |

`CMwId_ResolveCString` returns null for every non-`01` tag, including `0xFFFFFFFF`. It does **not** range-check the table index or reject an empty slot (`0xFFFFFFFF` offset). A fabricated tag-01 value can therefore return `blob+0xFFFFFFFF` or deref a null table. Do not call `GetName()` on untrusted tag-01 values.

### Plugin helper (question 2)

Find `g_CMwId_HashTables` with the ResolveCString pattern (next section). Count is `tables + 0x200` on this layout.

```angelscript
bool MwIdIsInterned(uint id) {
    if ((id & 0xC0000000) != 0x40000000) return false;
    uint payload = id & 0x3FFFFFFF;
    uint tableIx = payload >> 16;
    uint slot = payload & 0xFFFF;
    uint64 tables = FindCMwIdHashTables();
    if (tables == 0) return false;
    uint nTables = Dev::ReadUInt32(tables + 0x200);
    if (tableIx >= nTables) return false;
    uint64 table = tables + uint64(tableIx) * 16;
    uint64 slots = Dev::ReadUInt64(table);
    uint buckets = Dev::ReadUInt32(table + 8);
    if (slots == 0 || slot >= buckets) return false;
    return Dev::ReadUInt32(slots + uint64(slot) * 4) != 0xFFFFFFFF;
}

bool MwIdIsDefined(uint id) {
    uint tag = id & 0xC0000000;
    if (tag == 0) return true;                 // numeric #N, including 0
    if (tag == 0x40000000) return MwIdIsInterned(id);
    return false;                              // Unassigned / Internal Error
}
```

Do **not** hardcode `0x1FFB1B0`. Find it from `CMwId_ResolveCString` (below).

Live headers this session: 3 tables, 26669 buckets each, blob used `0x320A40`. Table 3+ is still null.

## Finding the globals after an update

Same recipe as `Lightmap.as` (`83 3D ?? ?? ?? ??` → RIP-rel). Anchor is `CMwId_ResolveCString`: it is the only site that does `AND EDX, 0x3FFFFFFF` then `LEA R8, [tables]` then the index decode (`MOVZX ECX, DX` / `SHR RAX, 16`).

```
81 E2 FF FF FF 3F 4C 8D 05 ?? ?? ?? ?? 8B C2 0F B7 CA 48 C1 E8 10
```

| | |
|---|---|
| Ghidra `search_byte_patterns` | **1** hit `1402d47f0` |
| On-disk `Trackmania.exe` (this build) | **1** hit `0x1402d47f0` |
| Live bytes | `81e2ffffff3f 4c8d05b369d201 8bc2 0fb7ca 48c1e810` |

Wildcard only the LEA rel32 (`?? ?? ?? ??`). The rest is the intern-index algorithm, not a data offset.

```
AND EDX, 0x3FFFFFFF          ; 81 E2 FF FF FF 3F     match+0
LEA R8, [rip+rel32]          ; 4C 8D 05 xx xx xx xx  match+6
MOV EAX, EDX                 ; 8B C2                 match+13  ← RIP after LEA
MOVZX ECX, DX                ; 0F B7 CA
SHR RAX, 16                  ; 48 C1 E8 10
```

```angelscript
const string Pattern_CMwId_HashTables =
    "81 E2 FF FF FF 3F 4C 8D 05 ?? ?? ?? ?? 8B C2 0F B7 CA 48 C1 E8 10";

uint64 FindCMwIdHashTables() {
    uint64 m = Dev::FindPattern(Pattern_CMwId_HashTables);
    if (m == 0) return 0;
    // LEA R8,[rip+disp32] is 7 bytes at m+6; disp32 at m+9; RIP = m+13
    return m + 13 + Dev::ReadInt32(m + 9);
}
```

This build: `m=0x1402D47F0`, rel32=`0x01D269B3`, `m+13+rel32=0x141FFB1B0`.

Same function, 32 bytes later: `48 03 05 ?? ?? ?? ?? C3` is `ADD RAX, [g_CMwId_StringBlob]` (RIP = that insn+7). Blob is also `HashTables - 0x10` on this layout (16-byte blob header immediately before the table array).

`g_CMwId_HashTableCount` is `HashTables + 0x200` (static array of 32 table slots). Sanity: `count` is in `1..32`, `tables[0].pSlots` readable, `tables[0].buckets` a prime near 20k (live: 26669). If the reserved table count changes, `+0x200` moves — fallback unique pattern in `CMwId_StaticInit` (MOV ECX,4 then count=1, then malloc the NullId singleton):

```
B9 04 00 00 00 C7 05 ?? ?? ?? ?? 01 00 00 00
```

1 hit at `1402d44ed`. Count = `(match+11) + ReadInt32(match+7)`.

Shorter prefix `81 E2 FF FF FF 3F 4C 8D 05` is also unique (1 hit) but keep the decode tail so a future `AND EDX, 3FFFFFFF / LEA R8` elsewhere cannot steal it.

Tag-check alone (`25 00 00 00 C0 3D 00 00 00 40`) is **8** hits — do not use it. The other 7 are “is this tag 01?” tests that do not LEA the tables.

## How names become ids

`MwIdString_IsNullSpelling` (`0x1402d4aa0`) is true for:

- length 0
- length 10 and bytes equal `"Unassigned"` (`0x141b72ae0`)
- length 6 and bytes equal `"NullId"` (`0x141b72aec`)

Then:

- `MwId_FromString32OrNull` (`0x1402d4d60`) — null spelling → write `0xFFFFFFFF`; else intern and OR `0x40000000`. No `#` numeric path.
- `CMwId_FromString32` (`0x1402d4b40`) — same null spelling; **or** a leading `'#'` parses as a tag-00 numeric (`value & 0x3fffffff`); else intern. `lookupOnly != 0` + miss → return false, dest unchanged.

Openplanet `MwId.SetName` / `nod.IdName = ...` is the create path (intern if missing). There is no script binding for lookup-only.

## Resolve / stringify

`CMwId_ResolveCString` (`0x1402d47e0`) — **RCX is `CMwId*`**, not a copied u32 (already noted on the plate, 2026-07-22):

```
if ((id & 0xC0000000) != 0x40000000) return NULL;
table = g_CMwId_HashTables[id.tableIndex];   // tableIndex = (id & 0x3fffffff) >> 16
offset = table.pSlots[id & 0xFFFF];          // empty slot in the table is 0xFFFFFFFF
return g_CMwId_StringBlob.p + offset;
```

`MwId_ToString32` (`0x1402d48f0`) is what script `GetName()` / `IdName` getter goes through (CMwNod script prop `0x1001000` in `FUN_1402cfb80`). Mode 0 is the human spelling (`"Unassigned"`, `"#N"`, interned name).

## Intern tables

`CMwId_StaticInit` (`0x1402d4480`, string `"CMwId::StaticInit"`):

- string blob grown to **1_000_000** bytes if smaller
- hash table 0 allocated with `next_prime(20000)` buckets, filled with `0xFFFFFFFF`
- table count = 1
- heap singleton `u32 = 0xFFFFFFFF` stored at `g_CMwId_NullIdSingleton` — script `CMwNod.Id` getter (`0x1001001`) returns this pointer when the nod’s id accessor is null

`CMwId_InternString32` (`0x1402d4630`):

- hash = MurmurHash2(`Hash_Murmur2` @ `0x1401262f0`) of the bytes, seed **`0x57489862`**
- bucket = `hash % nBuckets`, step = `hash % (nBuckets-2) + 1`
- probe 5 slots; on miss go to the next table (allocate on demand)
- insert: append `bytes + NUL` to the blob, store the blob offset in the slot
- return `(tableIndex << 16) | slot` (no tag; callers OR `0x40000000`)
- `lookupOnly != 0` and first empty slot → return `-1`

Compare is the engine string-view equality helper at `0x14010cc90` (length then bytes).

## Openplanet / E++

Script `MwId` is a 4-byte value type:

- `MwId()` → `0xFFFFFFFF`
- `MwId(uint)` / `.Value` get/set
- `.GetName()` → `MwId_ToString32` mode 0
- `.SetName(string)` → intern / null-spelling

E++ helpers: `GetMwId` / `GetMwIdName` (`src/Dev.as`, via a throwaway `CGameItemModel.IdName`), and `StrToMwIdValue` / `MwIdValueToStr` (`src/UI/TabMeta.as`, via a global `MwId`).

`CMwNod.Id` is the field at `+0x08`. `CMwNod.IdName` is the string view of that same field.

## How to re-check after a game update

```
research/ghidra_api.sh GET /search_byte_patterns 'pattern=81 E2 FF FF FF 3F 4C 8D 05 ?? ?? ?? ?? 8B C2 0F B7 CA 48 C1 E8 10&program=Trackmania.exe'
```

Expect **exactly 1** hit. More than one → tighten (add `48 03 C0 49 8B 04 C0 8B 04 88` after the SHR). Zero hits → compiler used different regs; fall back to the `"CMwId::StaticInit"` string (`43 4D 77 49 64 3A 3A 53 74 61 74 69 63 49 6E 69 74`, 1 hit) and the `LEA RCX, [tables]` in that function.

Always pass `program=Trackmania.exe`. Save with `GET /save_all_programs`.
